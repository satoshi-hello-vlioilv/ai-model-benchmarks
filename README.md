# ai-model-benchmarks

主要AIモデル（2026-10-04時点）の性能・価格・速度・仕様を、**1つのHTMLファイル**で比較するダッシュボードです。
`index.html` をブラウザで開くだけで動作します（外部ライブラリ・ネット接続不要）。

## 画面構成（スクロールレス・3階層）

| 階層 | UI | 内容 |
|---|---|---|
| 第1階層 | 左ナビ（数字キー `1`〜`9`・`0`） | 概要 / モデル特徴 / ベンチマーク / ベンチ解説 / 次世代・動向 / AIの歴史 / コスト / 速度・容量 / 比較 / 仕様一覧 / データ管理 |
| 第2階層 | 画面上部のタブ | モデル特徴（早見表・プロフィール）、ベンチマークのカテゴリ、ベンチ解説（全体像・個別解説）、次世代・動向（系譜と投入予定・拡散型LM・能力とコスト・基盤と普及・新領域・安全・規制）、AIの歴史（年表・性能の伸び） |
| 第3階層 | ホバー（ツールチップ）／クリック（右ドロワー） | 値の注記・出典・順位、モデル別の全スコアと仕様 |

上部の提供元チップ・「オープンのみ」・「旧世代も表示」は全画面に共通で効きます（ダブルクリックでその提供元のみ表示）。
画面・タブ・フィルター・比較対象はURLハッシュとブラウザに保存され、再訪時に復元されます。

## 解説画面

- **モデル特徴**：早見表（ひとこと要約、カテゴリ別の相対位置のヒートマップ、価格の位置、速度、文脈長）と、プロフィール（強み・注意点・向いている用途、データ上の上位指標、カテゴリ別の強さ、価格・速度・文脈・総合指数の立ち位置）。
- **ベンチ解説**：全体像（ベンチ×能力の対応表、飽和度と識別力の散布図、問題数の比較）と、個別解説（何を測るか、評価の流れ図、タスク構成、採点方法、読み方、スコア分布）。
- カテゴリ別の強さは、表示中モデルのうちデータのあるものの**順位**から算出します（100＝首位、0＝最下位）。データがない場合は推測せず「—」とします。

- **次世代・動向**：旧世代（中抜きの点）→ 現行（塗りの点）→ 今後の見通し（期間の帯）を提供元ごとに並べた系譜図と、技術・規制の動向カード（主要な数値・ミニグラフ・「意味すること」・出典）。見通しの確度は帯の塗り方で区別します（塗り＝公式、斜線＝報道、破線＝予測）。
- 旧世代モデルは上部の「旧世代も表示」で全画面に表示できます（系譜図では常に表示）。世代をまたいで比べやすいよう、SWE-bench Pro と Terminal-Bench 2.1 も収録しています。
- 一般提供されていないモデル（審査済み組織のみ）には「限定」の印を付けています。

- **拡散型LM**（次世代・動向のタブ）：自己回帰型との生成手順の違いを図解し、出力速度・応答時間の比較、2015年からの研究とモデルの年表、課題と対策、実用性の見立てをまとめています。拡散型モデルには「拡散」の印を付けています（速度はメーカー公表値）。
- **AIの歴史**：1943年の形式ニューロンから現在までの年表（時代区分・冬の時代つき、2010年より前は圧縮表示）と、学習計算量・パラメータ数・MMLU・文脈長・自律作業時間・価格の推移グラフ。データは `history`（`eras` / `milestones` / `growth`）で差し替えられます。

## データの最新化（HTMLの編集は不要）

「データ管理」画面から次のいずれかで取り込めます。取り込み前にスキーマ検証を行い、エラーがあれば取り込みません。

- **JSONファイルのドロップ／選択**：差分だけを書けば `id` 単位でマージ（全置換も選択可）
- **URLから取得**：CORS許可されたJSONのURLを指定。「起動時に自動で最新化」で毎回最新を取得
- **URLパラメータ**：`index.html?data=https://…/ai-models.json`

「追記用テンプレート」「現在のデータを書き出し」で書式の雛形を取得できます。

### スキーマ（`schema: 1`）の要点

```jsonc
{
  "meta": { "asOf": "2026-10-04" },                 // 基準日（30日超で「要更新」表示）
  "categories": [{ "id": "agentic", "label": "…", "short": "コード・自律" }],
  "abilities":  [{ "id": "code", "label": "コーディング", "short": "コード", "desc": "…" }],   // ベンチ解説の能力軸
  "kinds":      [{ "id": "agent", "label": "実行型", "desc": "…" }],                       // 評価形式
  "benchmarks": [{ "id": "tb4", "label": "Terminal-Bench 4.0", "short": "TB 4.0",
                   "category": "agentic", "unit": "%", "max": 100,
                   "zeroBased": false, "norm": "minmax",      // Elo等ゼロ起点に意味がない指標
                   "kind": "agent", "org": "…", "tasks": 66, "size": "66タスク", "budget": "…",
                   "format": "…", "scoring": "…", "why": "…", "flow": ["手順1", "手順2", "…"],
                   "composition": { "title": "タスク構成", "parts": [["ソフトウェア", 18]] },
                   "abilities": { "code": 2, "agent": 2, "knowledge": 1 },   // 2=主に測る 1=一部
                   "refs": [{ "v": 1000, "label": "人間専門家" }], "src": "出典ID" }],
  "providers":  [{ "id": "openai", "label": "OpenAI", "color": 1 }],  // color = 系列色スロット1〜8（null＝その他・グレー）
  "sources":    [{ "id": "aa", "label": "…", "url": "https://…" }],
  "models": [{ "id": "…", "name": "…", "provider": "openai", "released": "YYYY-MM-DD",
               "openWeights": "yes|partial|no", "context": 1000000, "maxOutput": 128000,
               "price": { "input": 2, "output": 10, "cachedInput": 0.2 },
               "speed": { "v": 100, "src": "aa" },
               "scores": { "tb4": { "v": 60.0, "src": "aa", "note": "注記" } },
               "summary": "ひとこと要約", "strengths": ["…"], "cautions": ["…"], "bestFor": ["…"],
               "legacy": false, "access": "limited" }],                 // 旧世代／限定提供
  "outlook": {                                                         // 次世代・動向
    "upcoming": [{ "id": "…", "name": "…", "provider": "google", "status": "training",
                   "window": ["2026-10", "2027-03"], "conf": "official|report|forecast",
                   "summary": "…", "points": ["…"], "srcs": ["出典ID"] }],
    "trends":   [{ "id": "…", "group": "capability|infra|frontier|safety", "title": "…", "lead": "…",
                   "stats": [{ "v": "16時間超", "l": "説明", "note": "注記" }],
                   "chart": { "type": "bars|log|flow", "title": "…", "unit": "%", "items": [["ラベル", 値, 範囲上限?]] },
                   "implication": "…", "srcs": ["…"] }],
    "events":   [{ "id": "…", "date": "YYYY-MM-DD", "lane": "regulation", "title": "…", "detail": "…" }]
  },
  "kpis":     [{ "label": "…", "metric": "bench:aa_index" }],     // 概要上部のKPI
  "useCases": [{ "label": "…", "metric": "value:aa_index", "filter": "open" }]  // 用途別推奨
}
```

`metric` 指定子：`bench:<id>`（ベンチ値）／`spec:speed`／`spec:context`／`price:blended`（入力3:出力1の混合単価）／`value:<id>`（ベンチ値÷混合単価）。
ベンチマークや提供元を追加すると、各画面（グラフ・ヒートマップ・表・レーダー）に自動で反映されます。

## データについての注意

- 値は各社発表値と第三者集計（Artificial Analysis、llm-stats、Vellum ほか）を収集したもので、値ごとに出典IDと注記を付けています。
- 推論努力（effort）や実行環境で数値は変わります。条件が異なる値は別系列に分け、**未公表の値は空欄のまま推測で補完していません**。

## 検証（評価関数）

`tests/evaluate.mjs` は、主要解像度（1536×864 = FHD@125%、1728×1152 = 2160×1440@125%、1920×1080、2560×1440）× 全画面 × ライト/ダークで次を自動検査します。

- ページ全体のスクロールが発生しないこと／各パネルの内容が縦横に切れていないこと
- グラフのラベルが領域外へはみ出さず、互いに重ならないこと
- 実行時エラーがないこと、埋め込みデータがスキーマ検証を通ること
- ドロワー・フィルター・データ取り込み（マージ／不正データの拒否）が動作すること

```bash
npm i -D playwright   # 初回のみ
node tests/evaluate.mjs [--shots <スクリーンショット出力先>]
```
